# US patch history of game.exe

The OpenShaiya catalogue lists 383 US patches, numbered 0 to 397. Only some of them replaced `game.exe`. This page lists those, with the catalogue's date and size, and says what can and cannot be read from the list. It is a list of file sizes; none of these files was opened except patch 106.

## In short

- 189 US patches carry a `game.exe`, from patch 0 (2007-12-18, 2,289,664 bytes) to patch 396 (2020-11-17, 3,697,024 bytes). **ref** (catalogue)
- This kit's client is patch 106. The next `game.exe` is patch 109, 2010-05-28, 3,211,264 bytes. **confirmed (file)** for 106, **ref** for 109.
- Patch 107 is a data file only (`Item.SData`) and the catalogue has no patch 108. This kit's own patch 108 file also holds only `Item.SData`. So the client file did not change from 106 to 108. **ref**
- Dates are catalogue dates, which are patch dates for US rows. Sizes jump at a few patches (23, 188, 200, 375); whether a jump marks an episode is *inferred* only, except where a public source dates the episode.

### Using this page

- **If you write a server:** a client's patch number says which `game.exe` your players run; match the opcodes of the [client pages](../client-packets.md) to patch 106 or later with care.
- **If you patch or mod the client:** another patch level means another file. Do not assume this kit's addresses fit it.
- **To check a claim yourself:** size and hash of a patch's `game.exe` against the catalogue; see [Tools and method](../tools-and-method.md).

## Releases

Totals of `game.exe` replacements per year (catalogue dates): 2007: 2, 2008: 14, 2009: 19, 2010: 22, 2011: 14, 2012: 18, 2013: 33, 2014: 15, 2015: 29, 2016: 11, 2019: 8, 2020: 4. There are none for 2017 and 2018. **ref**

## Patch 106, 107 and 108

Patch 86 (2009-11-03), 104, 105 and 106 are all 3,203,072 bytes with four different checksums. The patch 106 file has the same hash as this kit's client (**confirmed (file)**, hash and link time read). It was linked on 2010-04-26, the catalogue's date for the patch. Patch 107 has no `game.exe`; the catalogue has nothing for 108.
