# Episode 4.5

EP4.5 is this site's main client: `game.exe` as shipped with US patch 106, the build the other client pages describe. This page points at them and records which build it is. "EP4.5" is a community name; no publisher page read uses it.

## In short

- Our `game.exe` is the US patch 106 file of the OpenShaiya archive: same hash, same size, same link time.
- It was linked on 2010-04-26. Patch 107 changed only data and the catalogue has no patch 108, so the next `game.exe` is patch 109 (2010-05-28).
- Compared with EP3, the server side gained an auction house, union parties, Lua monsters and more. Those are server facts from a server page.
- A second regional "ep4.5" build exists (Russia, linked 2011-03-22). It is a different file.

### Using this page

- **If you write a server:** [the EP3 vs EP4.5 page](../../original/ep3.md) lists what EP4.5 added.
- **If you patch or mod the client:** the other pages of the Client tab apply to this build and no other; start at [Client systems](../client-systems.md) and [Graphics](../graphics.md).
- **To check a claim yourself:** hash the file and compare with the first 16 hex below.

## What changed for players

Content is listed on the server page, from the data of the EP4.5 server pack against the EP3 one: the auction house, union (raid) parties, enchanting, rune compose, remake and appraisal, Lua scripted monsters, party instances, and nine elements with absorption (**ref**, [what EP4.5 added](../../original/ep3.md)). No public article was found that dates these.

## What changed in the client

- Imports `d3d9.dll` plus `ijl15.dll`, `WINMM.dll`, `WS2_32.dll`, `DINPUT8.dll`, `DSOUND.dll`, `DDRAW.dll`; linker 7.10; sections `.text .rdata .data .rsrc`; not packed. **confirmed (file)**
- The same holds for the Russian `ep4.5` build (3,227,648 bytes, 24,576 bytes larger than ours). **confirmed (file)**
- Skill data: `Skill.SData` holds 3 levels per skill in this client's data format (EP5: 9, EP6: 15). **ref** ([File formats](../formats.md))
- HP, MP and SP: maximum and current values travel as 16-bit numbers in this client. **ref** ([Client facts](../CLIENT-FACTS.md#watch-hp-mp-and-sp-above-65535-and-current-values-above-32767))
- Everything about this client's code is on the [Client tab](../client-systems.md).
