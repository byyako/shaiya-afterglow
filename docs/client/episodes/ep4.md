# Episode 4

Episode 4, "Eternity", is the first episode with a dated public announcement for the West. This site has no client build that is clearly EP4: the one file the community labels EP4 is an edited copy of the client in this kit.

## In short

- A game-news site reported the release of Episode 4 "Eternity" on 2009-05-11 (page updated 2019-09-04).
- Headline content: revised experience requirements, server-linked battlefields, Oblivion Insula (a new dungeon map), a PvP ranking upgrade, item evolution, new skills, raids of up to 30.
- The "EP4" file in a public collection of client builds is this kit's client (same size, same link time, same sections) with a few bytes edited. It is not a separate episode.
- The kit's client was linked in April 2010, about a year after the article.

### Using this page

- **If you write a server:** [the EP3 vs EP4.5 page](../../original/ep3.md) is the nearest studied pack.
- **If you patch or mod the client:** a community "EP4" `game.exe` may be this client under another name; check the headers before trusting it.
- **To check a claim yourself:** compare size, link time and sections ([Tools and method](../tools-and-method.md)).
