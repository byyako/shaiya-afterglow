# done: plans of what has been built

Each file is the plan a feature was built from, kept as the record of the design and the decisions. The behaviour as built is described in the
matching notes of [`../../original/`](../../original/README.md); where a plan and the code disagree, the code wins.

- [`auction.md`](auction.md): the auction house.
- [`client-patches.md`](client-patches.md): the client data patches (`Item.SData` and the other data files).
- [`data-editing.md`](data-editing.md): the data editor.
- [`gm-commands.md`](gm-commands.md), [`gm-commands-2.md`](gm-commands-2.md): the operator (GM) commands, parts 1 and 2.
- [`guild-bank.md`](guild-bank.md), [`guild-ranking.md`](guild-ranking.md): guild houses, parts 3 and 2.
- [`obelisk-bosses.md`](obelisk-bosses.md): the boss spawns of `Obelisk.ini`.
- [`quest-drops.md`](quest-drops.md): monster drops, part 2 (quest items and sequence items).
- [`small-items.md`](small-items.md): small items and the fixes after the first live tests.
